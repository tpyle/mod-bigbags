# mod-bigbags

Gives every character a set of large bags at creation, so a new character is
not managing sixteen slots.

## Configuration (`mod_bigbags.conf`)

| key | meaning |
| --- | --- |
| `BigBags.Enable` | master switch |
| `BigBags.BagEntry` | the item to hand out (one per bag slot) |
| `BigBags.Announce` | tell the player at login |
| `BigBags.AnnounceText` | what to tell them |
